# BELLGRAM — التعديلات الجديدة

## الملفات
| ملف | ملاحظة |
|---|---|
| `index.html` | الواجهة (خلفية جديدة + الأصدقاء + السحب) |
| `server.js` | الـ API + البوت + إشعارات السحب |
| `lib.js` | منطق المستويات/التعدين (بدون تغيير) |
| `package.json` | بدون تغيير |

## متغيرات البيئة الجديدة
أضف في إعدادات السيرفر (Railway / Render / VPS):

```env
# ايدي تليجرام بتاعك (صاحب المشروع) — عليه هتوصلك رسائل السحب
ADMIN_CHAT_ID=8869642405

# (اختياري) أقل مبلغ للسحب، الافتراضي 1000 BELL
WITHDRAW_MIN_AMOUNT=1000
```

> ✅ القيمتين دول متسجلين بالفعل كـ default جوه `server.js`، يعني التطبيق شغال بيهم من غير أي إعداد إضافي.
> لو غيرت الـ ID بعدين، تقدر تكتبه في متغير البيئة `ADMIN_CHAT_ID` وهو هياخد الأولوية.
>
> ⚠️ مهم: لازم تبعت `/start` للبوت مرة واحدة من الحساب `8869642405`، لأن تليجرام بيمنع أي بوت يبعت رسالة لحساب لسه مبدأش المحادثة معاه.

## أوامر الأدمن في البوت
- `/withdrawals` — كل طلبات السحب المعلّقة.
- `/approve 12` — موافقة على الطلب رقم 12.
- `/reject 12` — رفض الطلب وإرجاع العملات لرصيد المستخدم.
- أو من الأزرار تحت رسالة الإشعار مباشرة (✅ Approve / ❌ Reject).

## ملاحظات
- عند إرسال طلب السحب يتم **حجز** المبلغ من رصيد التطبيق فوراً، ويرجع تلقائياً في حالة الرفض.
- لا يمكن للمستخدم إرسال طلب جديد قبل ما يتم البت في الطلب الحالي.
- العنوان في رسالة الإشعار داخل `<code>` في تليجرام = اضغط عليه ينسخ.
- قاعدة البيانات: جدول `withdrawals` يتم إنشاؤه تلقائياً عند التشغيل، مفيش migrations يدوية.
