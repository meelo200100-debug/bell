# PULSE NEWS — News & Market Bot (v2.0.0)

بوت ينقل أخبار الكريبتو من قنوات تليجرام ومواقع RSS إلى قناتك، مع تنبيهات الأسعار، ولوحة تحكم لك وحدك.

يتطلب المشروع Node.js 18 أو أحدث لأن عميل Telegram يستخدم `fetch` المدمج. يبدأ polling بعد نجاح تهيئة قاعدة البيانات فقط.

## المتغيرات (Environment Variables)
| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `BOT_TOKEN` | نعم | توكن البوت من BotFather |
| `ADMIN_ID` | نعم | رقم حسابك الشخصي في تليجرام. أصبح إلزامياً لحماية لوحة الإدارة والأوامر؛ لن يبدأ البوت بدونه |
| `WEBAPP_URL` | لزر `/panel` | رابط الخدمة، مثال `https://اسمك.onrender.com` |
| `TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN` | موصى به | قاعدة دائمة. بدونهما تتمسح البيانات مع كل نشر |
| `TARGET_CHANNELS` | لا | قنوات نشر إضافية مفصولة بفاصلة (`@Alkatiba21` مضافة دائماً) |
| `MAX_AGE_HOURS` | لا | أقدم عمر لخبر يتنشر، الافتراضي 12 |
| `MAX_PER_CYCLE` | لا | أقصى عدد أخبار في الدورة، الافتراضي 5 |
| `FETCH_INTERVAL_MS` | لا | مدة الدورة، الافتراضي 300000 (5 دقائق) |
| `PRICE_THRESHOLD_PCT` | لا | حد تنبيه السعر، الافتراضي 3 |
| `AD_FILTER` | لا | `0` لإيقاف فلتر الإعلانات |
| `AD_KEYWORDS_EXTRA` | لا | كلمات إضافية تُعتبر إعلانات، مفصولة بفاصلة |
| `AI_API_KEY` (أو `OPENAI_API_KEY`) | موصى به | مفتاح مزود AI للترجمة والتحرير العربي |
| `AI_BASE_URL` | لا | عنوان API متوافق مع OpenAI؛ الافتراضي `https://api.openai.com/v1` |
| `AI_MODEL` | لا | اسم النموذج؛ الافتراضي `gpt-4.1-mini` |
| `LIBRETRANSLATE_URL` / `LIBRETRANSLATE_KEY` | لا | بديل ترجمة عند تعذر AI |
| `NITTER_HOSTS` | لا | مصادر X تحتاج سيرفر Nitter خاص بك، وإلا تُتجاهل |

## الأوامر (لحسابك فقط)
`/panel` لوحة التحكم · `/on` `/off` · `/fetch` · `/status` · `/addtarget @قناة` · `/addsource @قناة_أو_رابط` · `/settemplate ...`

## التعديلات في v2.0.0
- نشر الأخبار باللغة العربية فقط. إذا فشلت ترجمة خبر غير عربي، يتم تخطيه بدلاً من نشره بالإنجليزية.
- حذف أي مصدر أخبار مباشرة من لوحة التحكم بزر × بجوار المصدر.
- يمكن إيقاف المصدر مؤقتاً أو تشغيله واختباره من اللوحة.
- يمكن إيقاف قناة نشر أو حذفها بشكل مستقل من اللوحة.
- تمت إضافة سجل تسليم مستقل لكل قناة؛ عند فشل قناة، يعيد البوت المحاولة للقنوات المتعثرة فقط دون تكرار النشر في القنوات التي نجحت.
- تمت إضافة فحص صحة تشغيلي إلى `/healthz` يشمل قاعدة البيانات وحالة الدورة وعدد التسليمات المعلقة.
- تمت إضافة ترجمة وتحليل AI اختياريان عبر `AI_API_KEY`؛ يصنّف الخبر إلى فئة وأولوية ويرصد طبيعته الترويجية، مع تقسيم الأخبار الطويلة إلى أجزاء، ثم الرجوع إلى LibreTranslate وGoogle وMyMemory عند فشل AI.
- تتم إضافة المصادر والقنوات الافتراضية مرة واحدة فقط؛ حذفها من لوحة التحكم لا يجعلها تعود بعد إعادة التشغيل.
- دعم إيموجي تيليجرام المميزة داخل قالب النشر باستخدام الصيغة `{{TG_EMOJI:ID|⭐}}`.
- لاستخراج المعرّف: افتح محادثة البوت، اختر إيموجي مميزة من لوحة إيموجي تيليجرام وأرسلها للبوت؛ سيرد بكود جاهز لنسخه إلى القالب.
- تنبيهات الأسعار أصبحت عربية فقط.
- تشديد إعدادات الأمان: `ADMIN_ID` مطلوب، وصلاحية بيانات Mini App صالحة لمدة 24 ساعة مع رفض التواريخ المستقبلية.
- تم استبدال عميل Telegram القديم بعميل API مباشر لتجنب سلسلة `request` المهجورة والثغرات التابعة لها.
- يزيل البوت التكرار الدلالي: إذا ورد الخبر نفسه بصيغ مختلفة من مصادر متعددة، تتم مقارنة العملة والاتجاه والأرقام وتشابه النص، ثم يُنشر مرة واحدة فقط.
- أزرار أسفل الخبر الأربعة تُرسل في صفين، زرّان في كل صف.
- يضيف البوت أسفلها زرًا ثابتًا باسم `مشاركة الخبر 🔴`، ويحوّل رابط المنشور الفعلي إلى رابط مشاركة Telegram بعد نجاح الإرسال.
- تتم مزامنة حزم الإيموجي المميزة المضافة في `DEFAULT_CUSTOM_EMOJI_PACKS` عبر `getStickerSet` وحفظ معرّفاتها لاستخدامها في القوالب.

## إعداد الذكاء الاصطناعي
أضف `AI_API_KEY` في متغيرات بيئة الاستضافة. لا تضع المفتاح في ملفات الواجهة أو داخل Git. يمكن تغيير المزود المتوافق مع OpenAI عبر `AI_BASE_URL` و`AI_MODEL`. إذا لم يُضف المفتاح، يستمر البوت باستخدام مسارات الترجمة الاحتياطية المجانية.

## ملاحظات
- لوحة التحكم تعمل من داخل تليجرام فقط وتتحقق من توقيعه ومن رقمك.
- `/healthz` للفحص (مفيد لخدمة مراقبة تمنع نوم الخدمة المجانية).
- `index.html` يشتغل سواء كان داخل `public/` أو في الجذر.
