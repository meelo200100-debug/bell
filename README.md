# News & Market Bot (v1.5)

بوت ينقل أخبار الكريبتو من قنوات تليجرام ومواقع RSS/Atom إلى قناتك، مع تنبيهات الأسعار، ولوحة تحكم لك وحدك.

يتطلب المشروع Node.js 18 أو أحدث. يبدأ polling بعد نجاح تهيئة قاعدة البيانات فقط.

## المتغيرات (Environment Variables)
| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `BOT_TOKEN` | نعم | توكن البوت من BotFather |
| `ADMIN_ID` | نعم | رقم حسابك الشخصي في تليجرام (أرقام فقط). يُتحقق منه عند الإقلاع |
| `WEBAPP_URL` | لزر `/panel` | رابط الخدمة، مثال `https://اسمك.onrender.com` |
| `TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN` | موصى به | قاعدة دائمة. بدونهما تتمسح البيانات مع كل نشر |
| `TARGET_CHANNELS` | لا | قنوات نشر إضافية مفصولة بفاصلة (`@Alkatiba21` مضافة دائماً) |
| `MAX_AGE_HOURS` | لا | أقدم عمر لخبر يتنشر، الافتراضي 12 |
| `MAX_PER_CYCLE` | لا | أقصى عدد أخبار في الدورة، الافتراضي 5 |
| `FETCH_INTERVAL_MS` | لا | مدة الدورة، الافتراضي 300000 (5 دقائق) |
| `PRICE_THRESHOLD_PCT` | لا | حد تنبيه السعر، الافتراضي 3 |
| `PRICE_COOLDOWN_HOURS` | لا | فترة تهدئة تنبيه السعر لكل عملة/اتجاه، الافتراضي 4 |
| `ALLOW_MISSING_DATES` | لا | `1` للسماح بالأخبار بدون تاريخ صالح (افتراضياً تُتخطى وتُسجل) |
| `INIT_MAX_AGE_SEC` | لا | صلاحية بيانات Mini App، الافتراضي 600 (10 دقائق) |
| `AD_FILTER` | لا | `0` لإيقاف فلتر الإعلانات |
| `AD_KEYWORDS_EXTRA` | لا | كلمات إضافية تُعتبر إعلانات، مفصولة بفاصلة |
| `LIBRETRANSLATE_URL` / `LIBRETRANSLATE_KEY` | لا | ترجمة الأخبار الإنجليزية للعربية (سيرفر LibreTranslate) |
| `NITTER_HOSTS` | لا | مصادر X تحتاج سيرفر Nitter خاص بك، وإلا تُتجاهل |

## الأوامر (لحسابك فقط)
`/panel` لوحة التحكم · `/on` `/off` · `/fetch` · `/status` · `/addtarget @قناة` · `/addsource @قناة_أو_رابط` · `/settemplate ...`

## التعديلات في v1.5
- تتبع تسليم دائم لكل خبر ولكل قناة (`news_deliveries`) مع محاولات وأوقات إعادة المحاولة. لا يُعتبر الخبر منشوراً عالمياً إلا بعد نجاح أو فشل دائم لكل الوجهات. لا يُعاد الإرسال للقنوات الناجحة. الإخفاقات المؤقتة فقط تُعاد مع احترام `retry_after` وbackoff.
- تواريخ الأخبار: لا يُستبدل التاريخ المفقود بوقت الجلب. يُستخرج تاريخ RSS/Atom ويُتحقق منه. الأخبار بدون تاريخ صالح تُتخطى افتراضياً (أو تُسمح عبر `ALLOW_MISSING_DATES=1`).
- محلل XML موثوق (`fast-xml-parser`) مع دعم RSS وAtom و`content:encoded` وCDATA، مع حدود حجم وعدد عناصر، وتعطيل معالجة الكيانات الخارجية.
- حماية SSRF: فحص DNS لكل طلب وإعادة توجيه، رفض العناوين الخاصة والمحجوزة وlink-local وmetadata (IPv4/IPv6 بما فيها mapped)، وتثبيت الاتصال على IP عام متحقق منه.
- تحسين تنظيف النص وكشف التكرار: لا تُحذف كلمات حقيقية؛ التكرار يتطلب تداخل نصي قوي وليس مجرد اتفاق عملة واتجاه ورقم.
- الترجمة: تقسيم النصوص الطويلة إلى مقاطع منطقية مع الحفاظ على الترتيب. فشل أي مقطع يمنع النشر الصامت الجزئي ويُسجل للإعادة. timeouts وإعادة محاولة محدودة. لا تُسجل المفاتيح.
- تنبيهات الأسعار: سياسة تهدئة قابلة للضبط لكل عملة/اتجاه، حالة محفوظة في قاعدة البيانات، رفض الأسعار الصفرية أو الناقصة.
- إيقاف آمن: `AbortSignal` يصل إلى `getUpdates` الحالي، backoff مع `retry_after`، إيقاف منظّم على SIGTERM/SIGINT يشمل polling والمؤقت والخادم. قفل الدورة يُجدد دورياً ومدة أطول.
- تحقق من طول الرسالة وقص آمن مع fallback للنص العادي. معالجة 400/403/404/429.
- `ADMIN_ID` رقمي صالح عند الإقلاع. صلاحية Mini App قصيرة (افتراضي 10 دقائق) مع رسالة واضحة عند الانتهاء. rate limiting على نقاط الإدارة.

## حدود ضمان عدم التكرار
Telegram `sendMessage` لا يوفر مفتاح idempotency. إذا نجح الإرسال على جانب Telegram لكن انقطع الاتصال قبل استلام الرد، قد يُسجل الإرسال كفشل مؤقت ويُعاد في دورة لاحقة. في هذه الحالة النادرة قد يظهر تكرار واحد. البوت يتجنب إعادة الإرسال للقنوات التي سجّل لها نجاحاً مؤكداً.

## مزودو الترجمة
- LibreTranslate (اختياري عبر `LIBRETRANSLATE_URL`/`LIBRETRANSLATE_KEY`)
- Google GTX (غير رسمي، قد يتغير أو يُحدّ)
- MyMemory (حد حجم منخفض)
الاعتماد على خدمات خارجية يعني مخاطر موثوقية وحدود معدل وخصوصية المحتوى المرسل. عند فشل الترجمة الكامل يُحفظ الخبر لإعادة المحاولة ولا يُنشر بالإنجليزية.

## ملاحظات
- لوحة التحكم تعمل من داخل تليجرام فقط وتتحقق من توقيعه ومن رقمك. عند انتهاء الجلسة تظهر رسالة تطلب إعادة الفتح عبر `/panel`.
- `/healthz` للفحص (مفيد لخدمة مراقبة تمنع نوم الخدمة المجانية).
- `index.html` يشتغل سواء كان داخل `public/` أو في الجذر.
- لا تضع أسراراً في المستودع أو السجلات. المفاتيح تُقرأ من المتغيرات البيئية فقط.
